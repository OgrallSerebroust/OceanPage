## Features

* **Catalog and search:** A product catalog divided into categories that are edited, like the products themselves, through the admin panel. Users also can find their beloved products using fast and easy-to-use search.
* **Cart and delivery:** Users can add products to cart and then purchase delivery in available area. They can check area availability on the map.
* **Sales and coupons:** For regular customers available a complete system of sales, coupons and special offers.
* **Warehouse integration:** There is integration with 1C Warehouse system. Users can see badge on product card corner, which shows product remaining, if it's less than a certain amount. Interaction between services is performed through CSV.

> [!NOTE]
> Project repository contains not newest version. And most important, that it's not for open use. That repository using in project-presentaion way.
